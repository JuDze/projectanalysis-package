# Changelog

## 0.1.0 — 2026-10-30

- Initial standalone package distribution for Unity 6000.3.10f1.
- Texture, model and audio analysis with 13 configurable rules and Low/Medium/High findings.
- Reviewable importer fixes, confirmation before applying changes, current-session Undo and rechecks.
- Local rule settings and current-analysis fix-state storage.
- Analysis report snapshots, JSON export and optional report upload to a compatible web server.
- Web connection checks and session-only access-token storage.
- Package distribution excludes development tests, test-only assembly access and Unity Test Framework.
